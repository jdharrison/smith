## Implementation limits

All four Smith identity values must match. Do not trim, case-fold, accept prefixes, or ignore unknown attributes. Keep MIME, printable-ASCII secret validation, encryption, timestamps, owner/UID, three-second keyring budget, NoAutoStart/no-unlock/no-Prompt, immutable generations, JSON activation, uncertainty and no-retry semantics unchanged. Do not touch the nine existing items. The separate timestamp-integrity timing concern is not the observed blocker and remains outside this correction.
